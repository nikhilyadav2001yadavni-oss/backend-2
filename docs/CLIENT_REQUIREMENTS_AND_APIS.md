# 📋 What We Need From You

## Simple Checklist of Required Items

This document lists everything we need from you to build your mobile app. Don't worry if you don't understand the technical terms - we'll help you get everything set up!

---

## 🔑 1. BSCScan API Key (Required)

**What is it?**  
A free API key to verify USDT transactions automatically.

**What we need:**
- [ ] BSCScan API Key

**Where to get it:**
1. Go to: https://bscscan.com/register
2. Create a free account
3. Go to: https://bscscan.com/myapikey
4. Click "Add" to create a new API key
5. Copy the API key and send it to us

**Link:** https://bscscan.com/myapikey

---

## 📧 2. Email Service (Required)

**What is it?**  
A service to send OTP codes and notifications to users via email.

**What we need:**
- [ ] Email service account (choose one option below)

### **Option A: Gmail (Free & Easy)**
- [ ] Gmail account email
- [ ] Gmail account password
- [ ] Enable "App Password" in Gmail settings

**How to get Gmail App Password:**
1. Go to: https://myaccount.google.com/security
2. Enable 2-Step Verification
3. Go to: https://myaccount.google.com/apppasswords
4. Create app password for "Mail"
5. Copy the 16-character password

**Link:** https://myaccount.google.com/apppasswords

### **Option B: SendGrid (Recommended for Business)**
- [ ] SendGrid account
- [ ] SendGrid API Key

**Where to get it:**
1. Go to: https://signup.sendgrid.com/
2. Create free account (100 emails/day free)
3. Go to Settings → API Keys
4. Create new API key
5. Copy and send to us

**Link:** https://signup.sendgrid.com/

---

## 💰 3. MetaMask Wallet Address (Required)

**What is it?**  
Your wallet address where users will send USDT deposits.

**What we need:**
- [ ] MetaMask wallet address (for receiving USDT)
- [ ] Network: Binance Smart Chain (BSC)

**How to get it:**
1. Install MetaMask: https://metamask.io/download/
2. Create or import wallet
3. Switch network to "Binance Smart Chain"
4. Copy your wallet address (starts with 0x...)
5. Send the address to us

**Important:** Make sure you have the private key/seed phrase saved securely. We will need access to verify transactions.

**Link:** https://metamask.io/download/

---

## 🗄️ 4. Database (Required)

**What is it?**  
A place to store all user data, transactions, and app information.

**What we need:**
- [ ] Database account (we recommend MongoDB Atlas - it's free)

**Where to get it:**
1. Go to: https://www.mongodb.com/cloud/atlas/register
2. Create free account
3. Create a free cluster (M0 - Free tier)
4. Create database user (username & password)
5. Get connection string
6. Send us: Username, Password, and Connection String

**Link:** https://www.mongodb.com/cloud/atlas/register

**Note:** Free tier includes 512MB storage - enough to start!

---

## 🖥️ 5. Server Hosting (Required)

**What is it?**  
A server where the app backend will run.

**What we need:**
- [ ] Server hosting account (choose one)

### **Option A: DigitalOcean (Recommended - Easy)**
- [ ] DigitalOcean account
- [ ] Create a Droplet (server)
- [ ] Send us: Server IP address and SSH access

**Where to get it:**
1. Go to: https://www.digitalocean.com/
2. Sign up (get $200 free credit)
3. Create Droplet → Choose Ubuntu
4. Minimum: $6/month plan (1GB RAM)
5. Send us the server details

**Link:** https://www.digitalocean.com/

### **Option B: AWS (If you already have account)**
- [ ] AWS account
- [ ] EC2 instance created
- [ ] Access keys

**Link:** https://aws.amazon.com/
